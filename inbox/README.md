# art-inbox — 画像候補の受け渡し用ブランチ

**このブランチは main にマージしない。PR も作らない。**

**画像の試作・候補は、種類を問わず、すべて一旦ここに入れる。** 設定資料のイラスト（三面図・表情・ポーズ・客・背景・小物）、ドット絵、ブランディング、アニメ（caking-anime）用の絵のどれも同じ。caking-anime の PR や Google Drive など、別の場所に候補を置かない。

ここに置けば、Claude のセッションやオーナーに確実に届く。
ルールの正本は main の `docs/art/asset-management.md`「候補の置き場所」。

- 置き場所: `inbox/<日付>/<名前>-c<候補番号>.png`（例: `inbox/20261020/cerise-icon-c1.png`）
- 生成ツールが出した画像を**無加工のまま**置く（縮小・減色・切り抜きをしない）
- push する前に main の最新を取り込む必要はない。このフォルダにファイルを足すだけでよい
- 採用された候補は、通常のブランチと PR を通して main の `art/` に正式登録する
