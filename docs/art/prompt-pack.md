# CAKING！ 画像素材 プロンプト集

ゲームとアニメで使う画像素材を、作業量がほぼ同じになるよう9回分（バッチ）に分けたもの。
1バッチ＝Codexの1回の作業で、画像生成は4回前後。

- **第1部（バッチ1〜4）**：ティザー第1話「海風が運んだ鍵」に必要な素材。先にやる
- **第2部（バッチ5〜9）**：ゲーム素材の描き直し。ティザーの後でよい

保存・採用・pushの手順は `docs/art/asset-management.md` に従う。

---

## 全バッチ共通

### Codexへの最初の一文（毎回、プロンプトの前に貼る）

```
docs/art/asset-management.md と docs/world/ の設定に従って作業して。
作業前に git pull。生成した候補は art/_inbox/ に保存して私に見せ、私が「採用」と言うまで正式な場所に置かないこと。
採用後は台帳とプロンプトを記録して、art/ と docs/art/ だけをコミットしてpush。public/images/ には触らないこと。
```

### 絵柄の共通指定（すべてのプロンプトの末尾に付ける）

```
【絵柄】
・添付の「ミフィの3面図（mify-ref）」と完全に同じ絵柄にそろえる
・繊細なペン線を活かした、淡い水彩風の着彩。塗りで線を潰さない
・中世ヨーロッパ風ファンタジー世界。現代的な小物は描かない
・文字、ロゴ、透かしは入れない
```

キャラの画像は「背景は白一色」、背景の画像は「人物なし」を必ず付ける。

### 添付する参照画像

| 記号 | ファイル | いつ添付するか |
|---|---|---|
| A | `art/characters/mify/mify-ref`（最新の採用版） | すべてのバッチ |
| B | 元の絵柄の漫画ページ | キャラの新規デザイン時 |
| C | そのバッチで先に採用した画像 | 同じキャラ・同じ場所の2枚目以降 |

## バッチ1　ミフィの3面図修正と表情シート（生成3回）

### 1-1　3面図の修正 → `mify-ref-v2.png`
添付：A（v1）

```
添付の3面図を修正してください。変更点は1つだけです。
・後ろ姿の頭のリボンを、正面・横向きと同じく「本人の左側」に付け直す（後ろ姿では画面の左側に見える）
それ以外の絵柄、色、構図、服はまったく変えないでください。
```

### 1-2　表情シート前半（口と目） → `mify-expressions-a-v1.png`
添付：A（v2）

```
添付のキャラクター「ミフィ」と同じデザイン・同じ絵柄で、アニメの口パク用の表情シートを描いてください。

【構図（全コマ共通・厳守）】
・正面向きのバストアップ（胸から上）
・頭の位置、大きさ、角度、髪、猫耳、リボン（本人の左側）、服を全コマで完全に同じにする
・変えるのは目と口だけ
・背景は白一色

【4×2の8コマ、この順に並べる】
1行目：口「あ」／口「い」／口「う」／口「え」（目は普通に開いた、やわらかい表情）
2行目：口「お」／口を閉じる／目を半分閉じる（口は閉じる）／目を閉じる（口は閉じる）
```

### 1-3　表情シート後半（感情） → `mify-expressions-b-v1.png`
添付：A（v2）、C（1-2の採用版）

```
2枚目の表情シートと完全に同じ構図・同じ大きさで、ミフィの感情の表情を8コマ描いてください。
変えるのは目・眉・口・頬の赤みだけです。

【4×2の8コマ、この順に並べる】
1行目：感動して見とれる／目を閉じて匂いをかぐ／やわらかく微笑む／困り笑い
2行目：満面の笑顔／照れて少し目をそらす／元気いっぱい／普通（基準の顔）
```

**確認すること**：16コマすべてで頭の位置がずれていないか。ずれていたら、ずれたコマだけ描き直させる。
