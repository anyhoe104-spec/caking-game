## 不具合 / 改善要望

深刻度が「クラッシュ / 保存消失 / 進行不能」に該当するものはありません。以下は操作性と演出に関する指摘です。

### 1. ミフィのセリフが背景と混ざって読みにくい

- 対象: フローティング表示のヒント（`.hintStrip`、`src/App.css`）
- 症状: 透過処理により背景と混ざり、文字が読み取りにくい
- 要望: 透過率を下げる、または透過しない
- 重大度: 表示
- 修正コミット: `87f74af`（[PR #17](https://github.com/anyhoe104-spec/caking-game/pull/17)、2026-09-26 マージ）

### 2. ケーキの飾りパーツが全レシピで共有される

- 対象: `src/game/storage.js` の `cakeStyle`
- 症状: 飾りパーツの選択が単一の状態として保持されるため、レシピを変えても同じ飾りが適用される
- 要望: **ケーキごとにパーツ情報を保持する**
- 補足: コードを確認したところ `cakeStyle: defaultCakeStyle()` が単一オブジェクトで、レシピ別のキーを持たない。**実装どおりの挙動であり、退行ではなく未完成**。修正にはセーブ形式の変更と移行処理が必要
- 重大度: その他（機能の未完成）
- 修正コミット: `eeed7c9`（[PR #23](https://github.com/anyhoe104-spec/caking-game/pull/23)、2026-09-29 マージ、Issue #21）。飾りはレシピごとに保持し、店頭には最後に作ったケーキを出す。パーツは一度買えば全レシピで使える

### 3. 店舗装飾が店舗画面のどこに反映されているか分からない

- 対象: `src/components/ShopDiorama.jsx`
- 症状: 装飾を購入・装備しても、店舗画面の変化に気づけない
- 補足: 描画自体は実装されている（`harbor-lamp` は `✦`、`rose-table` は `❀ ❀ ❀`、`royal-case` は `ROYAL PATISSERIE` の文字）。**未実装ではなく、変化が小さすぎて認識できない**
- 要望: **装飾が大きく出るようにする。** グラフィックや音の質の向上は今後の課題とし、まずは演出が確実に実装されていると確認できることを優先する
- 重大度: 表示
- 修正コミット: `bd0befe`（[PR #18](https://github.com/anyhoe104-spec/caking-game/pull/18)、2026-09-26 マージ）。装飾を拡大し、装飾名ラベルを常時表示
