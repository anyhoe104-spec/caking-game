# CAKING 現在の開発状況

更新日: 2026-09-29

## 現在地

MVPはGitHub Pagesで公開中です。工房の演出、物語8章、セーブ運用、実機確認で出た指摘の修正まで、すべて `main` に入り、公開サイトにも反映済みです（2026-09-29 17:17 JST、Pages デプロイ run 21 の成功を確認）。

- 公開URL: https://anyhoe104-spec.github.io/caking-game/
- GitHub: https://github.com/anyhoe104-spec/caking-game（Public）
- 公開方式: `main` → GitHub Actions（`deploy.yml`）→ GitHub Pages。**PRごとに自動で走るテストはない**。テストは各作業者が手元で実行する
- 現行営業時間: 180秒
- セーブ: `localStorage` V4（V2・V3からの移行に対応）
  - 飾りは**レシピごと**に保持する（`cakeStyles`）。旧形式の単一 `cakeStyle` は全レシピへ引き継ぐ
  - バックアップはファイルへの保存と、ファイル・全文からの復元に対応
- サウンド: BGM5曲 / 効果音15種 / ボイス9種（すべて自作の生成音源）
  - 起動直後に自動再生を試み、ブロックされたときはタップで開始する
  - 一時停止中と非表示中は鳴らさない
- 検証（2026-09-29、`main` = `31262ea`）
  - 単体テスト45件、lint、build
  - ブラウザ検証 `scripts/verify-*.cjs`（bgm / atelier / save / story / playthrough）

## 将来検討
