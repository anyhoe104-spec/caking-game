# CAKING 現在の開発状況

更新日: 2026-08-14

## 現在地

CAKINGのMVPはGitHub Pagesで公開済み。Phase 0〜7のゲーム機能と画像素材は `main` に統合済みで、PC・スマートフォンからゲーム本体と主要リンクが正常に動作することを確認した。

- 公開URL: https://anyhoe104-spec.github.io/caking-game/
- GitHub: https://github.com/anyhoe104-spec/caking-game
- リポジトリ: Public
- 公開方式: `main` → GitHub Actions → GitHub Pages
- 現行営業時間: 180秒
- ボトムナビ: 営業 / レシピ / デコレーション / 食材 / スタッフ
- セーブ: `localStorage` V3（V2からの移行対応）

## 将来検討

ユーザーアカウント、端末間セーブ同期、ランキング、オンラインイベント、決済が必要になった場合に限り、バックエンドとデータベースを導入する。現在のMVPでは導入しない。

リアルタイム物理演算や大規模3D描画が必要になるまでは、React / Vite構成を維持する。
