# 工房のグラフィック・工程音（2026-09-30）

作業者: Astra（Codex）。開始スキルから `main` の `3a243ed` を基点に改修。

## 現在地と今回の範囲

ゲーム進行・8章40ページの物語・レシピ別装飾・保存/復旧・起動時BGMは統合済み。
今回の改修は既存の水彩背景を生かしたSVGの前景、ミニキャラ、製造時の光と音です。
背景画像の全面差し替え、BGM/ボイスの新録、課金、進行データの変更は含みません。

- 店内: 木枠、ガラスケース、布、調理道具、旗、ハーブ。家具差分と最後に作ったケーキを維持。
- キャラ: 髪先、耳の動き、衣装/顔の細部。待機客はその場で呼吸し、到着時のみ移動。
- 製造: 道具の質感、完成時の光と粒子。既存レシピ画像の白い背景を乗算でなじませる。
- 音: 9工程に専用の短い音。既存SE/マスターの音量とミュートに追従。
  スキップ・工程切替・中断・アンマウント時に解放。音自身がAudioContextを再開しない。
- 動きを減らす設定では新しい装飾も静止。演出省略時は完成SEだけで、工程音は鳴らない。

## 再検証

`npm test` / `npm run lint` / `npm run build`。
ブラウザは Playwright を利用し `node scripts/verify-av.cjs`。
必要なら `PLAYWRIGHT_MODULE` と `PLAYWRIGHT_EXECUTABLE` で既存環境を指定。
`ATELIER_QA_DIR` 指定時は3幅の店内と完成画面を保存。
日本語フォントのない検証環境では `STORY_QA_FONT` にwoff2を指定できる（製品には注入しない）。

専用検証は320/390/768px、9音の実ノード生成/停止、ミュート、中断、工程同期、動き軽減を確認。
`verify-atelier.cjs` は8レシピ24工程、装飾、保存、スキップ、日報/終幕、表示幅を確認。
`verify-bgm.cjs` は起動と中断/復帰を確認。ヘッドレスの自動再生ブロック再現は未対応。

## 聴感・実機で残る確認

1. スピーカーとイヤホンで短い工程音がBGM/完成SEに埋もれないか、鋭すぎないかを確認。
2. 製造中に背景へ移動→復帰。再開するまで無音、スキップ後に工程音が残らないこと。
3. 動きを減らす設定で店内と完成演出が静止し、通常時の描画が滑らかなこと。

自動検証で波形の有限性・振幅・端点のフェードを確認しても、聴感の合格や実機60fpsを意味しません。
Web Audio非対応時は新しい工程音を省略します。既存29音源は変更していません。
BGMの録音品質改善と聞き取れる日本語ボイスは引き続き別の改修候補です。
