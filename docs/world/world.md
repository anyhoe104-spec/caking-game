# CAKING！ 世界観シート

ゲーム・アニメ共通の「正」となる設定。素材生成・脚本・UI文言はすべてこれに従う。
「未定」「案」と書かれた項目は確定前。

## 世界

- 中世ヨーロッパ調のファンタジー世界
- 文明レベル：産業革命直前くらい（帆船・手工業・印刷物・新聞はある。蒸気機関・電気はない）
- 気候は現実世界のヨーロッパに準じる
- 階級制度あり（王族・貴族・平民）

## 地理

- **王都**：現実世界のフランス・ロレーヌ地方に相当する位置
- **港町マサリエ（舞台）**：王都から南西。現実世界のマルセイユに相当する地中海沿岸の港町
  - 地中海交易で砂糖・柑橘・ナッツ・香辛料・花が集まる
  - 白い帆の商船が行き交う、明るい港町
- 港町の名前：**マサリエ**（マルセイユの古名「マッサリア」のもじり）

## 人間と獣人

- 人間と獣人が共存している
- 獣人は耳・しっぽ程度の動物的特徴に加え、種族ごとの身体的特徴を持つ
- 現実世界に実在する哺乳類の獣人はほぼすべて存在する（犬・猫・ウサギ・馬・羊など）
- 各種族は特徴を活かした仕事に就いているが、社会的な立場は総じて人間より下
- 人口比
  - 都市部：人間 約7割／獣人 約3割
  - 地方：人間と獣人が半々
  - 森に住む獣人の種族もいる
- 職業傾向の例：猫耳族はメイドが多い（男女問わず）

### 種族の呼び方のルール

「動物名＋その種族の目立つ特徴＋族」で呼ぶ。

| 種族 | 呼び方 |
|---|---|
| 猫 | 猫耳族 |
| 羊 | 羊毛族 |
| 豹 | 豹紋族 |
| 犬 | 犬尾族 |

新しい種族もこの形で命名する。

### 描写のトーン

身分差は世界の厚みとして存在するが、正面から重く描かない。
「獣人の職人のケーキを最初は嫌がった客が、味で認める」のように、ケーキ屋らしい形で触れる程度にとどめる。

## 物語の前提

- 主人公（ご主人様）は港町マサリエの海運商会の会長の息子、15歳
- 自分で店舗を運営することを、一人前になるための試験として父から課されている
- 店は前の店主が手放した古いケーキ店（ゲーム第1章「海風が運んだ鍵」）
- 主人公の家：マルシャン家。父が一代で海運商会を興し、男爵位を得た
  - 古い貴族からは「商人上がり」と見られている含みがある

## 命名ルール

- 人物名は食品、特に香辛料・ハーブにちなむ（アニス、クミン、シナモン、ペッパー、ローレルなど）
- スイーツ由来の名前は避ける。例外はミフィとミル（2人で「ミルフィーユ」。下記キャラ設定を参照）
- 苗字には命名ルールを適用しない。中世フランス風の普通の苗字にする
- 既存の客キャラ12名の名前（さくら、ひろと等）は、このルールに合わせて後で付け直す

## 表現の方針

- 絵柄：作者の元の絵柄（繊細なペン線、光の入った大きな瞳、フリルやリボン）にゲーム・アニメとも寄せる。既存のゲーム素材は作り直す
- アニメでは主人公を画面に出さない。一人称視点か後ろ姿のみ。キャラはカメラ（＝ご主人様）に話しかける
- 主人公は名前を持たない。呼ばれるときは「ご主人様」、または苗字のみ
